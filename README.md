# By the Book · מה הפעם?

אפליקציית אינטרנט לטלפון שעוזרת לבחור ספר כשמגיעים לספרייה.
המידע האישי נשמר רק בטלפון. אין שרת ואין הרשמה.

## איך מריצים במחשב

```bash
python3 -m http.server 8000
```

ואז לפתוח את `http://localhost:8000` בדפדפן.

## מבנה התיקייה

| קובץ | מה יש בו |
|---|---|
| `index.html` | שלד הדף |
| `css/style.css` | העיצוב |
| `js/app.js` | המסכים ומה קורה בלחיצה |
| `js/recommend.js` | איך נבחרים 3 הספרים |
| `js/store.js` | שמירת המידע בטלפון |
| `js/shelf.js` | המדף, שדרות הספרים והספר שיוצא מהמדף |
| `js/install.js` | ההסבר המצויר להוספה למסך הבית |
| `sw.js` | מאפשר לאפליקציה לעבוד בלי אינטרנט |
| `manifest.webmanifest`, `icons/` | שם האפליקציה והאייקון במסך הבית (`icons/icon.svg` הוא המקור) |
| `data/categories.js` | הקטגוריות (אפשר לערוך ולהוסיף) |
| `data/books.js` | רשימת הספרים לאפליקציה. **נוצר אוטומטית, לא עורכים ידנית** |
| `tools/books_source.json` | רשימת הספרים המקורית: כאן מוסיפים ומתקנים ספרים |
| `tools/build_books.py` | מחפש כריכות ב-Open Library ובונה את `data/books.js` |

## הוספת ספר

1. מוסיפים רשומה ל-`tools/books_source.json`, בדומה לרשומות הקיימות.
2. מריצים `python3 tools/build_books.py`.

אם הכריכה שנמצאה לא נכונה, מוסיפים לספר `"cover": <מספר הכריכה ב-Open Library>`,
או `"cover": null` כדי להציג כריכה מצוירת.

## עדכון גרסה

כשמשנים קבצים, מעלים את המספר `VERSION` בקובץ `sw.js` (למשל מ-`v2` ל-`v3`), כדי שהטלפונים יקבלו את הגרסה החדשה.
